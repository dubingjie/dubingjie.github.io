网络排查入门：ping、nslookup 与 SSH

2026-08-14 / ping · DNS · SSH

区分连通性测试、域名解析和远程登录，记录三个常用命令的用途。

1、ping 命令

ping 命令是做什么用的？

ping 命令是用来诊断网络的，测试我的主机与目标主机（用 IP或者域名）网络是否连通的

在命令行下使用：

ping 域名：看它解析到了哪个 IP

ping IP 地址：验证网络是否连通

ping 127.0.0.1 本机

ping 114.114.114.114 外网

ping baidu.com 域名

2、nslookup 命令

用来查询DNS域名解析的过程

nslookup baidu.com 域名到IP

nslookup baidu.com 114.114.114.114 指定用114DNS服务器查询

3、ssh

ssh 是远程操作另一台计算机的网络协议，而且全程加密

ssh 做了三件事：远程操纵计算机、加密、判断是不是服务器发给你的信息（防止被骗）

密码登录 VS 密钥登录：

密码登录：输入密码

密钥登录：自己配置一把锁和钥匙，钥匙自己留着，锁安装到服务器上

生成密钥用：ssh-keygen.exe
